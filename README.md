# Лабораторная работа: Создание процессов

Этот репозиторий содержит три программы, демонстрирующие работу с процессами в операционной системе Linux.

## Структура репозитория

| Файл | Описание |
|------|----------|
| `task1.c` | Выводит идентификаторы текущего (PID) и родительского (PPID) процесса |
| `task2.c` | Создаёт копию процесса через fork() и показывает, как меняются идентификаторы |
| `task3.c` | Создаёт новый процесс через fork() и заменяет его код с помощью exec() |

## Описание программ

### 1. task1.c — Простой вывод PID и PPID
Программа получает и выводит на экран:
- **PID** (Process ID) — идентификатор текущего процесса
- **PPID** (Parent Process ID) — идентификатор родительского процесса

### 2. task2.c — Создание копии процесса через fork()
Демонстрирует системный вызов `fork()`:
- Родительский процесс создаёт дочерний процесс
- Дочерний процесс получает **новый PID**
- PPID дочернего процесса становится равен PID родителя
- Наглядно видно, как идентификаторы меняются

### 3. task3.c — Создание процесса с новым кодом через fork() + exec()
Показывает замену кода процесса:
- `fork()` создаёт новый процесс
- `execl()` заменяет код дочернего процесса на команду `ps -f`
- Дочерний процесс выполняет другую программу, а родитель ждёт завершения

## Компиляция и запуск

Для компиляции любой из программ используйте gcc:

```bash
# Компиляция
gcc task1.c -o task1
gcc task2.c -o task2
gcc task3.c -o task3

# Запуск
./task1
./task2
./task3
